# Squarespace Update Guide for Molyx Labs

This guide is ordered for speed. Follow it top to bottom and you will end up with a much stronger first version of the site without rebuilding everything at once.

## 1. Fix The Immediate Credibility Issues

### A. Fix the broken homepage CTA

In Squarespace:
- Open `Pages`
- Open the homepage
- Find the `Work With Us` button block
- Change the link target from blank to `/contact` or your audit booking link
- Rename the button to `Book a Free Automation Audit`

Do this first. Right now the homepage has a dead CTA.

### B. Remove misleading team language

Replace:
- `one of our project managers will contact you`

With:
- `You will hear back directly from the founder`

You are selling founder-led specialist work. The site should reflect that.

### C. Remove default Squarespace social links

In Squarespace:
- Open `Settings`
- Open `Social Links`
- Remove any default Squarespace Instagram/Twitter profiles
- Add your real profiles only if you actually use them

If you do not have active social proof yet, it is better to show none than fake defaults.

Use the `Contact Page Copy` section in [molyxlabs_homepage_copy.md](/Users/jacobmolyneux/Desktop/Molyx/molyxlabs_homepage_copy.md#L165).

For each page:

- set a real meta description
- make the first heading specific

## 8. Add Basic Proof

Even before you have full case studies, add one of these:
- a founder credentials block
- an example workflow diagram
- a short `typical outcomes` section such as `5 to 10 hours saved per week`

Once you have your first client, replace placeholders with:
- case study
- testimonial
- measurable result
